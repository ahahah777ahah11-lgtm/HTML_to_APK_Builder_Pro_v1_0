HTML to APK Builder Pro — الإصدار 1.0

المحتويات:
- index.html: لوحة إعداد عربية متجاوبة تعمل محليًا في المتصفح.
- project-config.json: يتم إنشاؤه من داخل التطبيق عند التصدير.
- BUILD_GUIDE_AR.md: يتم إنشاؤه من داخل التطبيق عند التصدير.

التشغيل:
1) افتح index.html في متصفح حديث.
2) أدخل اسم التطبيق ومعرّف الحزمة ورابط الموقع وإصدار التطبيق.
3) حدد الميزات والصلاحيات المطلوبة.
4) احفظ الإعدادات أو نزّل project-config.json ودليل البناء.

مهم:
هذه النسخة لوحة إعداد وتصدير، ولا تنتج APK فعليًا بذاتها. لبناء APK يلزم قالب Android WebView وAndroid SDK وJDK وGradle أو خدمة CI. فحص البناء داخل الصفحة فحص شكلي للحقول فقط ولا يشغّل مترجم Android.
